### 💼 Портфолио и Проекты

#### 🗄️ [LiteDB: Встраиваемая сетевая СУБД на C++](ссылка_на_репозиторий)
Собственная система управления базами данных, написанная с нуля. Демонстрирует глубокое понимание структур данных, системного I/O и сетевых протоколов.
* **Движок хранения:** Реализовано гибридное/колоночное хранение с поддержкой сжатия блоков (Zlib / LZ4) и дельта-кодирования.
* **Транзакции и индексы:** Разработан транзакционный журнал и быстрый доступ по ключам в памяти (`unordered_map`).
* **Сетевой сервер:** Написан многопоточный TCP-сервер для обработки клиентских подключений и передачи бинарных/текстовых протоколов.
* **Парсинг:** Разработан базовый парсер SQL-запросов (SELECT, INSERT, UPDATE, DELETE).
* **Интеграция с ORM:** Разработан кастомный драйвер на Python (DB-API 2.0) и диалект для SQLAlchemy.

#### 🎙️ [GStreamer VAD Plugin / Проект YADRO](ссылка_на_репозиторий)
Системная разработка для обработки аудиопотоков в реальном времени.
* Разработан плагин Voice Activity Detection на C++ для архитектуры пайплайнов GStreamer с использованием библиотеки `libfvad`.
* Проведено тестирование и валидация точности алгоритма на бенчмарке LibriSpeech.

#### ✈️ [Инспектор аэропортов: Управление данными](ссылка_на_репозиторий)
Приложение для работы с реляционной базой данных, построенное по принципам SOLID.

* **Архитектура:** Четкое разделение бизнес-логики и слоя работы с базой данных, реализация паттернов проектирования.
